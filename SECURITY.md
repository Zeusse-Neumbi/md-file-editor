# Security Policy

## Supported versions

Only the latest tagged release is supported with security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately
through GitHub's **Report a vulnerability** button on the repository's Security
tab, or email the maintainer at the address on the GitHub profile.

Include the affected version, operating system, reproduction steps, and impact.
You will receive an acknowledgement as soon as possible.

## Scope

MD Editor is a local desktop application. Relevant reports include unsafe
Markdown rendering, path traversal in file operations, and unintended command
execution. Reports about the security of third-party dependencies are welcome
but should also be sent upstream.
