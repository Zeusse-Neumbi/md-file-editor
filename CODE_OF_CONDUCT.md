# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, and keep criticism focused on the work. Harassment, discrimination, and personal attacks are not acceptable in issues, pull requests, discussions, or any other project space.

Report unacceptable behavior privately to the maintainer through the contact details on the GitHub profile. Reports will be reviewed and handled as confidentially as possible.
