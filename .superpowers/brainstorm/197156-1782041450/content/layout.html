Getting Started

Welcome to the project! This guide will get you up and running.

Installation

npm install

Usage

To start the server, run:

npm run dev

Note: Make sure you have Node.js >= 18 installed.

Layout behavior summary

  • Sidebar — appears only in folder/workspace mode. Toggle with Ctrl+B. Shows file tree.
  • Editor pane — dark theme, monospace font, syntax-highlighted Markdown. Status bar shows cursor position.
  • Resize handle — drag to adjust editor/preview ratio. Default 50/50.
  • Preview pane — light theme (or dark), renders GFM with code highlighting.
  • Title bar — shows file path, modified indicator (*), save status.
